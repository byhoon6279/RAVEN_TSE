# RAVEN Open Science

This repository contains the open-science artifacts for RAVEN, including the perturbation framework, aggregated evaluation data, figure-generation scripts, and the released dynamic trace package used for runtime sanity checking of representative original/adversarial-example pairs.

## Environment & Requirements

We tested the analysis code on Ubuntu 20.04.6 with Python 3.10.

Required Python libraries:

- `pefile`
- `lief`
- `pandas`
- `numpy`
- `seaborn`
- `matplotlib`

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Dataset Access

If you cannot access the full dataset or code directly from this repository, download the complete artifacts from:

[Google Drive download link](https://drive.google.com/drive/folders/1P4KIVouHTfKtIl6QqFnjtWyBcfVIL-k8?usp=drive_link)

After downloading, unzip each archive into the corresponding subdirectory under `Data/`.

## Released Sanity-Check Traces

The `sanity_check/` directory contains the public release package for the dynamic execution traces used to sanity-check whether representative RAVEN-generated variants preserved the runtime behavior of their corresponding originals.

Key points:

- The manifest contains 62 pairs total.
- All 62 original/variant pairs used in the sanity check are publicly included.
- The release contains dynamic traces only; it does not contain malware binaries.
- Samples are identified by SHA-256 in filenames and in `trace_manifest.csv`.

For one source trace, non-record trailing NUL padding after the final valid event was omitted during public export. No execution-event record was removed or modified.

To verify the released trace package:

```bash
cd sanity_check
python3 scripts/summarize_traces.py
```

Expected output:

```text
manifest_rows,62
status,included,62
included_pairs,62
missing_files,0
content_mismatches,0
exact_event_sequence_matches,61
terminal_record_only_differences,1
event_sequence_differences,0
```

For the detailed package description, see [sanity_check/README.md](sanity_check/README.md).
